# Módulo `physdual.eval` — Avaliação e Métricas

Implementa as métricas obrigatórias de regressão de afinidade DTA: Concordance Index (CI), Mean Squared Error (MSE), correlações de Pearson ($r$) e Spearman ($\rho$), e $r_m^2$.
Inclui agregação estatística (média ± desvio-padrão) sobre múltiplas seeds e splits (`random`, `cold_drug`, `cold_target`).
