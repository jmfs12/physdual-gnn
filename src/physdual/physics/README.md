# Módulo `physdual.physics` — Fase 6 (Opcional / Ablação)

Módulo opcional para injeção de bias energético analítico (potenciais de Lennard-Jones e eletrostática de Coulomb) sobre representações latentes droga-alvo.
Não utiliza AutoDock Vina nem DiffDock; sua contribuição será avaliada estritamente por estudo de ablação em relação ao modelo sem termos físicos.
