# Módulo `physdual.screening` — Fases 8 e 9

Pipeline de triagem virtual, filtros de druglikeness/ADMET e interpretabilidade via Grad-AAM para geração de hipóteses de reposicionamento de fármacos.
Qualquer par candidato avaliado (como hipóteses envolvendo Donepezil, Brexpiprazole ou DYRK2) é tratado exclusivamente como hipótese computacional sujeita a validação.
